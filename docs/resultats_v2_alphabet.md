# Résultats V2 — alphabet statique (26 lettres, signeur unique + augmentation)

- Accuracy globale : 0.87 (156 échantillons de test, découpage aléatoire)
- LIMITE CONNUE : un seul signeur réel ; évaluation non indépendante par
  personne. Résultat optimiste, à refaire dès qu'un 2e signeur est collecté.
- J systématiquement confondu avec Y (et I) : lettre dynamique (rotation)
  capturée comme une image statique -> confirme la distinction
  statique/dynamique du cahier des charges (section 9). À exclure du
  modèle statique, à traiter en V3 (séquentiel).
- Confusions mineures cohérentes avec la littérature : R/U, K/R, M/B/O
  (configurations de doigts visuellement proches).
